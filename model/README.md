# 模型权重

`tiny_rnn.npz` 是可以直接运行的微型示例权重，包含词表和模型参数，当前大小为 147,246 字节。

这个小文件直接纳入 Git，方便克隆后体验。另保留下面已复查的学习里程碑权重；其他训练产物默认由 `.gitignore` 忽略，避免反复提交二进制权重。

`learn_rnn_step005.npz` 是第二十六课保存的字符 RNN 权重，大小为 2,686,396 字节，参数数为 719,723；词表大小 5,547，隐藏维度 64。它从种子 42 的随机参数开始，仅在真实训练语料上更新了 5 步，并未完成一轮训练，也尚未验证文字生成质量。

文件包含五组 float32 参数、模型格式 `tiny_rnn_char_v1`、隐藏维度、完整词表配置和已完成步数。使用 `scripts/learn/11_train_steps.py` 中的 `load_checkpoint` 与 `scripts/learn/07_tiny_rnn.py` 的模型加载；它与 `scripts/example` 的示例权重格式不同。固定前三批验证子集的加载前后损失均为 8.628433227539062，五组参数无损往返检查通过。

该里程碑作为“每课完成后完整上传”的明确例外纳入 Git。文件 SHA-256 为 `db80ce4b3d2bc584f7e746b456223e5084c731c45d31b35fc832e6eca3a9c45f`。重新运行学习脚本会从初始模型训练五步并覆盖此文件，不会自动接着训练；它也没有保存数据迭代位置，尚不构成精确断点续训。

训练实验时指定另一个输出路径，可以保留基线：

```powershell
python scripts/example/train.py --output model/experiment_01.npz # 将实验权重写入另一个文件。
```

如需分享较大的模型，后续单独选择 GitHub Release、Git LFS 或模型托管服务，并在文档中记录配置、数据版本和测评结果。
