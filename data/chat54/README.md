# 第五十四课：混合语言与可验证中文任务

language_v3是实际使用的语言数据版本。来源均为已冻结训练/验证：data/chat48/pretrain_*、data/transformer45/*（joe-chiu/TinyChineseStories固定提交ad789c9d622bfbdeecdc90df2041b3ba458e0368）及data/splits/*四书完整章节。原文和分组文件不改，不读取测试正文。故事作者声明GPT-3.5合成、CC-BY-4.0；旧权重混合上游限制仍适用，不给整个模型重新声明商业许可。

language与language_v2保留更新前的初版清单和抽查记录，仅其npy数组不重复纳入Git；本课未使用它们训练。初始诊断主题及治疗/诅咒叙事被保守排除；v2又发现坏开头和Word count尾注，v3排除一个已知坏样例并去掉训练5篇末尾生成元数据。review.json明确仅审阅8个首尾片段，不是全文事实核验。简繁原文保留，小说情节不作事实问答。

curriculum为本项目原创10类模板与800条程序化可验证标签：训练639条/636有序输入组，验证161条/159组。每条都通过逆运算、单调性、重数或集合等不变量核验，CI十类错误标签也必须被拒绝。不是800条独立人工标注；交换律或排序置换的全部语义等价未合并，验证仍共享模板，不是通用聊天测试。

sft_catalog.json将旧53课一般问答和新任务保留为独立组件，并登记未来平衡采样建议。当前只准备数据，没有对这800条做SFT；不可把新增条数直接写成模型已学会的任务数。

实际语言训练按每组旧通用4/故事3/四书1个256-token窗口混合。所有来源、审核版本、分词器、数组及目标数量见language_v3/manifest.json；整个训练和输出局限见[课程](../../docs/lesson54_language_and_tasks.md)。
