# 语料与清洗结果

## 来源记录

学习者采集并核对了四份中文小说文本，提供的来源线索为：

https://github.com/weiyinfu/SiDaMingZhu/tree/master/src

文件名为三国演义.txt、水浒全传.txt、红楼梦.txt、西游记.txt。本记录说明学习者提供的来源，不声称本地文件与上游某一提交逐字一致，也未核验上游版本完整性和许可。此目录不包含笔记中另行收藏的中英对照语料。

## 目录

- `corpus/`：原始采集文本，不由清洗脚本覆盖。
- `corpus_processed/`：第二课生成的 UTF-8 文本，保留每本书的独立文件。

在项目根目录运行：

```powershell
python scripts/learn/01_inspect_data.py # 检查原始文本的路径、开头和字符统计。
python scripts/learn/02_clean_data.py # 删除空白行和每行首尾空白，重新生成清洗结果。
```

清洗保留正文、标点、标题和行内空格。尚未划分训练集、验证集或测试集，也尚未将这四份语料用于模型训练。

## 第二课结果

统计值按 Python 读取并统一换行后的字符串长度计算，不是文件字节数。

| 文件 | 原始字符数 | 清洗后字符数 | 减少 |
| --- | ---: | ---: | ---: |
| 三国演义.txt | 599,460 | 597,979 | 1,481 |
| 水浒全传.txt | 900,163 | 897,427 | 2,736 |
| 红楼梦.txt | 865,713 | 864,306 | 1,407 |
| 西游记.txt | 720,681 | 718,733 | 1,948 |
| 合计 | 3,086,017 | 3,078,445 | 7,572 |

Git 将文本换行统一为 LF。本地 Windows 上 write_text 默认可能写为 CRLF，因此文件字节数与清洗后的字符数变化不必一致。
