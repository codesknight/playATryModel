# 第四十五课问答复盘：从注意力形状到断点续训

本页依据真实问答记录学习者的作答与纠正过程。答对小题只说明该题理解有进展，不等于已经独立实现、训练或完整掌握源码。模型代码和实际六轮训练仍为助手代实现、代跑。

## 形状与注意力

|知识点|最初作答与纠正|最后一次表现|
|---|---|---|
|拆头|先答(2,10,32)，漏了4个头这一维；应为(2,4,10,32)|解释后继续答对后续矩阵形状，拆头题尚未另行复答|
|QK转置相乘|(10,32)×(32,10)|(10,10)，正确|
|因果范围|第3位置先答只能看1、2；实际上可以看自己，读完第3字预测第4字|第5位置可看1～5，正确|
|加权汇总V|0.75×[4,0]+0.25×[0,8]|[3,2]，正确|
|多头拼接|4头各32维，拼回原宽度|(2,10,128)，正确|
|残差相加|[1,2]+[0.3,-0.5]|[1.3,1.5]，正确|
|前馈网络回到128维|128→512→128后才能与原表示相加|回答保持维度对齐，正确|
|输出分数|输入(2,10,128)，共享输出矩阵(128,6799)|(2,10,6799)，正确|

完整路径：输入编号(B,T)→字符与位置向量(B,T,128)→Q/K/V拆头(B,4,T,32)→注意力分数(B,4,T,T)→汇总V(B,4,T,32)→拼接(B,T,128)→残差与前馈网络→词表分数(B,T,6799)。分数不是概率；softmax沿最后的词表维度进行。

## 索引与自回归生成

位置从1开始讲解时，第10位置读完前10个输入，预测第11个符号。代码从0编号，因此第一条输入的末位置是logits[0,-1,:]，得到6799个候选分数；logits[0,0,:]是第一条输入第一个位置的预测，目标是第2个符号。学习者一度把批次、位置和负索引混淆，随后对logits[1,-1,:]回答第二条输入的最后位置，经补充明确它取得的是该位置对下一符号的分数，而非字符本身。

argmax返回词表编号，不是字符；学习者对此答对。查vocab的tokens后才能解码。模型生成“起”后，当前无KV cache实现应再次读取“春风起”整个上下文，不只读取“起”。学习者起初答只取“起”，解释后答对下一步应读取“春风起了”。上下文最多保留最近128个编号；遇到EOS或长度上限停止。

## Teacher forcing与损失

训练时输入真实前文，生成时接回自己预测的符号。学习者起初认为训练预测“起”前的“又”来自模型预测，解释后改答真实前文。训练中即使上一位置预测错，也不替换本批预先准备好的真实输入；因果遮罩仍防止看到未来输入。

学习者答对(2,10,6799)展开为(20,6799)，目标对应展开为(20,)。交叉熵直接接受logits，不先手动softmax。20位置中3个-100目标被忽略，平均分母为17，学习者答对。两批10位置损失2、30位置损失4，整体按位置平均为(10×2+30×4)/40=3.5，学习者答对，不能直接平均批次均值。

## 训练、验证、梯度和裁剪

验证只前向和算指标，不执行backward或step。eval影响Dropout等层的行为，inference_mode关闭梯度记录；两者作用不同。学习者起初不知道验证是否更新参数，并把backward当成更新参数，解释后正确表述：不执行step，参数仍停留在更新前。

|操作|准确含义|
|---|---|
|zero_grad|清除参数上已有的.grad，不清模型参数或AdamW历史|
|backward|计算并累加梯度，通常不修改参数|
|clip_grad_norm_|超限时统一缩小梯度，通常不修改参数|
|step|优化器根据梯度及自身历史更新参数|

已有grad=0.4，再算0.3且不清除，累加为0.7；学习者起初不会，解释后答对先清除旧梯度再计算则为0.3。当前普通一批一更新需要每批清梯度；以后若有意做梯度累积，会改为若干微批后再step与清除，这不是矛盾，需另讲有效目标加权方式。

裁剪范数0.6、阈值1不需缩小，学习者最初答需要，已经纠正；范数2、阈值1的缩放比例为1/2，学习者答对；梯度-0.8乘0.5等于-0.4，也答对。裁剪上限是最大允许值，不是要求范数都恰好变成1。

## step、epoch和检查点

学习者答对100窗口、批大小32、保留尾批，需要4步（32+32+32+4）。本项目26104窗口、批大小32，一轮816次更新，尾批24窗口；6轮4896步，学习者答对。同一窗口跨轮重复使用不等于新增独立语料。

三轮验证损失4.5、4.2、4.4，应选第2轮为best，学习者答对；last保留第3轮最新进度，两者目的不同。

学习者起初认为只加载模型参数、重建空AdamW也能产生相同下一步，经解释后答对需恢复模型参数和优化器状态。AdamW状态含m、v和累计t；续训还需匹配数据游标、排列、随机状态和训练配置。只生成不需要优化器历史。

完成第300批更新后保存，下一批应为第301批，学习者初答第300批，已纠正。从0编号时第301批的代码索引是300，不要把索引和序号混用。整轮816批结束后进入下一轮，学习者答对。

新一轮本轮批次序号从1开始，但累计更新数延续。上一轮816次后下一批累计817；学习者最初答1，解释后对两轮后下一批答1633，正确。本次Transformer训练完6轮4896次后，完整恢复并再更新一次应为4897。
