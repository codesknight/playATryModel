# 第四十四课：增加训练轮数和更新步数

本课应学习者要求增加实际训练，由助手代跑；不记录为学习者已手写完成。保持模型、四书语料、词表、窗口32、批大小64、学习率0.001及全局梯度裁剪1不变，只增加训练预算。从第四十三课最佳RNN的完整状态继续，包含Adam的一阶矩、二阶矩和步数。

## 预先规定的预算

最多新增8轮、9576次更新、600秒批次边界截止。每轮末完整验证并保存三个固定开头、两种解码方式的全部生成样例；原起点也参与最佳选择。600秒包括阶段内的周期评估和保存，到达后不启动新训练批次；最后的评估及恢复核验另计，不是强制终止进程的硬截止。

本次未更换模型结构，未添加外部语料，未用测试集挑选模型。

## 轮数、步数和数据量的关系

一轮的更新数是 ceil(76584 / 64) = 1197，而不是简单丢弃尾批后取整。8轮新增1197×8=9576步。原累计4788次，加上9576次，得到14364次。

增加轮数是反复学习同一训练集，不是新增独立语料。每轮使用新的可复现窗口排列，本次原数据种子47加轮号4至11，即使用51至58。窗口内部的字符顺序始终保留，否则会破坏预测任务。

Adam继续使用原先m、v及t。学习率保持0.001，改变学习率和模型结构会引入新的变量，本次没有同时改变。代码通过恢复检查点和数据游标来接续训练，而不是每轮重新创建初始模型。

## 如何判断增加训练是否有效

本次每个轮末的完整验证损失都下降，说明这次延长训练对同一验证任务确有帮助。但第一轮下降约0.039，最后一轮只下降约0.0026，收益已经减小。只凭该曲线不能断言过拟合；还需要结合训练损失等证据。也不能保证未来每一轮都继续变好。

## 实操：复用同一个续训脚本

现在 `scripts/experiments/continue_recurrent.py` 支持指定来源、输出目录、报告文件和逐轮验证。默认参数仍可重现第四十三课；以下命令才是本课的八轮实验，会覆盖本课输出：

```powershell
& 'D:\apps\anaconda3\envs\vllm-qwen\python.exe' scripts/experiments/continue_recurrent.py --source model/lesson43/lesson43_best.pt --output-dir model/lesson44 --report docs/training_runs/lesson44.json --max-epochs 8 --max-steps 9576 --max-seconds 600 --evaluate-each-epoch # 保留Adam历史并逐轮验证。
```

只加载最佳模型生成，不再训练：

```powershell
& 'D:\apps\anaconda3\envs\vllm-qwen\python.exe' scripts/experiments/generate_recurrent.py --model model/lesson44/lesson44_best.pt --prompt "宝玉听了" --length 60 --seed 42 # 沿用固定采样参数。
```

先阅读新增的四个命令行选项，再看外层轮末的capture调用。内层仍是一批一次前向、反向、裁剪和Adam更新。检查命令是 `python scripts/ci/check_lesson44.py`，在CPU重算完整验证，并核对源文件、八轮数据排列、预算、尾批游标、Adam累计历史与全部固定样例编号。
