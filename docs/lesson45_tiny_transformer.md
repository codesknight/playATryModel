## 代码块二：整理训练窗口

脚本：`tiny_transformer.py`中的load_windows。

每篇独立编码为BOS、正文、EOS。取输入x与向后错一位的目标y；每个窗口最多128位置。输入输出都为(B,T)，logits为(B,T,V)。BOS让模型知道文档开始，预测EOS让模型学习文档结束，不是把一个故事的最后一个字接到下个故事。

不足128的尾段也保留：输入右侧补0，目标补-100。PyTorch交叉熵忽略-100，统计分母也排除它。这里0既可作输入补齐也代表UNK；因为所有补齐都在右侧，真实位置不能通过因果注意力看到这些右侧填充，因此不另设PAD符号或键填充遮罩。

每个正文字符与EOS都作为目标一次，不预测BOS。实际训练26104窗口，每轮3204871真实目标。完整验证411454目标，其中四书317763（317717正文字符＋46个EOS），新故事93691（93460正文字符＋231个EOS）。与旧课丢弃尾段的316960目标口径不同。

## 代码块三：Q、K、V与因果自注意力

脚本：`tiny_transformer.py`中的Block。

输入x形状(B,T,D)，先做LayerNorm，再分别线性变换得到Q、K、V。Q表示当前位置用于匹配前文的查询，K用于被匹配，V是根据匹配权重汇总的内容。这些是可学习的数值投影，不是人工给每个字指定的含义。

```text
Q = LN(x) W_Q + b_Q
K = LN(x) W_K + b_K
V = LN(x) W_V + b_V
A = softmax(Q K^T / sqrt(d_head) + M)
attention_output = A V
```

D=128，4头，每头d_head=32。Q/K/V各从(B,T,128)变成(B,4,T,32)。QK转置后形状(B,4,T,T)，沿最后维度对所有可见键位置归一化。除以sqrt(32)控制分数尺度，避免点积随维度增大导致softmax过度集中。

M在未来位置j>t为负无穷，其余为0，因此位置t只能看0至t。输入本身是当前字符，目标是下一字符，所以允许看当前位置，不允许偷看下一字。实现调用[PyTorch因果缩放点积注意力](https://docs.pytorch.org/docs/2.11/generated/torch.nn.functional.scaled_dot_product_attention.html)，显式is_causal=True。

本课检查：保持前三个输入不变，只改后面的字，多层模型前三个位置的输出必须不变；改动处输出还要确实变化，避免常数模型蒙混过关。随后核对所有参数都收到有限梯度。

## 代码块四：残差、前馈网络和位置表示

```text
x = token_embedding(ids) + position_embedding(positions)
u = x + attention(LayerNorm(x))
x_next = u + Linear_2(GELU(Linear_1(LayerNorm(u))))
logits = LayerNorm(last_block_output) @ token_embedding.weight.T
```

位置表示让模型区分字符出现的顺序。这里使用128个可学习位置向量。前馈网络先把128扩到512，再压回128；GELU提供非线性。残差相加保留原路径，同时让各层学习修正。先归一化称为Pre-LN。

4个块各有独立参数；4个头是单块内部将128维分成4份计算，并不是4层。输出层复用输入表示表，称为权重共享，这并不要求输入输出向量值完全相同。

RNN把前文逐步压到隐藏状态；因果自注意力让当前位置直接对窗口内可见位置加权。它有能力使用128字前文，但不能保证训练后就能保持长程语义，更不代表无限记忆。生成超过128时只保留最近128个编号，位置重新从0计数；本课60字固定样例未触及该边界。

## 参数量与效率计算

|模块|公式|参数数|
|---|---|---:|
|字符表示表/共享输出|V×D=6799×128|870272|
|位置表示表|T×D=128×128|16384|
|每块注意力线性层|4D²＋4D|66048|
|每块前馈网络|8D²＋5D|131712|
|每块两个LayerNorm|4D|512|
|4块合计|4×198272|793088|
|最终LayerNorm|2D|256|
|总计|VD＋TD＋4(12D²＋13D)＋2D|1680000|

float32权重约1680000×4=6720000字节（6.72MB）。梯度另需约6.72MB；AdamW的m、v约13.44MB；还要算激活、logits、工作区等，不能把权重大小当成训练显存。完整检查点含参数和AdamW历史，约20.5MB，仍远小于1GB。

以一次乘法加一次加法算2 FLOPs，忽略LayerNorm、激活和softmax等小项：每块每窗口前向约24TD²＋4T²D；4块加输出投影2TDV，本配置约0.458 GFLOPs/窗口，B=32约14.65 GFLOPs/批前向。含反向与优化器的实际成本更高，常用约前向3倍作粗估，不是实测硬件吞吐。注意力T²项使上下文翻倍的代价不只是翻倍。显式注意力分数若完整存储，B×头数×T²×4约8.39MB/块，融合内核可能不按这个方式保存；本配置输出logits本身约111.4MB/批。
