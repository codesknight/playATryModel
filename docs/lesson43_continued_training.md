## 为什么要连同 Adam 一起恢复

Adam不仅使用本批梯度，还保存历史一阶矩 m 和二阶矩 v：

```text
m_t = 0.9*m_(t-1) + 0.1*g_t
v_t = 0.999*v_(t-1) + 0.001*g_t²
m_hat = m_t / (1-0.9^t)
v_hat = v_t / (1-0.999^t)
参数 = 参数 - 0.001*m_hat/(sqrt(v_hat)+1e-8)
```

只加载模型再新建空Adam，会清除m、v和t，下一次更新就与不中断训练不同。本次从t=2394继续，到t=4788；脚本没有调用随机初始化来替代源模型。保存的还有随机状态、下一批游标和当前窗口排列。下一轮排列由原数据种子47加轮号得到，本次使用第2、3轮的49、50，而不是再次使用47、48。

可以按三个代码块阅读：第一块恢复模型、优化器和游标；第二块循环做前向、反向、裁剪、更新，并推进游标；第三块完整验证、保存、比较最佳。每个窗口仍从零隐藏状态开始，不把不同章节接成同一段记忆。

实际GPU核验：复制当前模型作不中断参考，再从文件恢复另一份，给两份相同下一批，参数最大差为0.0，并核对下一步的Adam历史。核验只发生在副本，不增加正式训练预算。
